# InkTrail

AI Temporary Tattoo Studio — by Rombaut Solutions

Standalone React + Vite website for `inktrail.rombautsolutions.be`

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deploy the `dist/` folder via Cloudflare Pages (or any static host).  
Point the `inktrail.rombautsolutions.be` CNAME to your Cloudflare Pages deployment.

## Features

- Dark/Light theme toggle (persisted in localStorage)
- NL/EN language toggle (persisted in localStorage)
- Single-page with smooth scroll sections: Home, Services, Why, AI, Contact
- Sticky navbar with scroll-aware styling
- Tattoo flash aesthetic: UnifrakturMaguntia + Cinzel + IM Fell English typography
- Decorative SVG flash ornaments in hero
- Contact via WhatsApp + email (no form submission needed)
